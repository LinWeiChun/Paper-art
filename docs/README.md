# PaperArt

剪紙藝術作品展示平台。

## Tech Stack

### Frontend
- React
- React Router
- Axios
- CSS
- React Icons

### Backend
- Spring Boot
- Spring Security (JWT)
- MySQL
- Lombok

---

## 功能

### 前台

- 首頁
- 作品列表
- 作品詳情
- 作者
- 分類
- 搜尋
- 篩選
- 分頁

### 後台

- JWT登入
- 作者CRUD
- 分類CRUD
- 作品CRUD
- 上傳縮圖
- 精選作品
